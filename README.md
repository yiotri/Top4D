# Top4D
3D viewer for AFM topography scans

A largely faithful remake of **Top3D**, a topography viewer originally written in 2005 using OpenGL during an internship at ElbaTech srl, a developer of microscopy solutions.
The original took about three weeks to build; this remake took less than an hour with Anthropic's Claude Opus 5.5.

## Samples
The included samples are scans acquired with ElbaTech's AFM and its SPMagic software, then processed in WSxM 4.0:
- CD data pits
- CR-39 ion tracks
- TGG01 grating
- Cashmere fibre
- Microstructure array
